Projetos

Smart Home - Aplicação Cliente/Servidor com Socket

Projeto desenvolvido no curso Técnico em Redes de Computadores para a disciplina de Internet das Coisas, utilizando Python e a biblioteca Socket, com base na arquitetura Cliente/Servidor e no protocolo TCP.

A aplicação simula um ambiente residencial inteligente, permitindo controlar e monitorar dispositivos como lâmpadas, tomadas, sensores de presença, ar-condicionados e termômetros.

CanekArt

Projeto desenvolvido no curso Técnico em Redes de Computadores para a disciplina de Programação Web, com o objetivo de desenvolver um site para a mini empresa CanekArt.

O projeto foi desenvolvido com foco na criação de uma página web funcional e organizada, utilizando tecnologias de desenvolvimento front-end.

Instituto Alpha

Projeto desenvolvido no curso Técnico em Informática para a disciplina de Programação Web, com o objetivo de transformar um site institucional (fictício) em uma aplicação web dinâmica utilizando PHP, MySQL e o padrão arquitetural MVC.

O sistema possui autenticação de usuários, painel administrativo protegido por sessão, gerenciamento de cursos, serviços, publicações e inscrições, além de formulários integrados ao banco de dados e envio de mensagens de contato.

Agenda de Eventos Tecnológicos

Projeto desenvolvido no curso de Análise e Desenvolvimento de Sistemas para a disciplina de Laboratório de Programação I, com o objetivo de aplicar conhecimentos sobre estruturas de dados homogêneas, utilizando vetores e matrizes.

A aplicação simula uma agenda de eventos tecnológicos organizados por dia e turno, permitindo cadastrar, buscar, listar e atualizar eventos, além da geração de relatórios com filtros.

Sistema de Oficina Mecânica

Projeto desenvolvido no curso de Análise e Desenvolvimento de Sistemas para a disciplina de Linguagem de Programação Orientada a Objetos, utilizando Java, Java Swing e banco de dados MySQL.

O sistema permite gerenciar veículos de uma oficina, possibilitando o cadastro, consulta, busca, edição e exclusão de carros e motos, além da autenticação de usuários e armazenamento dos dados no banco de dados.
