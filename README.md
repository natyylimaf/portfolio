## 📚 Sobre o projeto

Portfólio desenvolvido durante a disciplina de **Desenvolvimento de Aplicações Web I**, utilizando apenas HTML, CSS e JavaScript puros. Reúne minha formação, meus conhecimentos e os projetos que desenvolvi nos cursos de Redes de Computadores, Informática e Análise e Desenvolvimento de Sistemas.

O visual é inspirado em uma **janela de terminal**, com fonte monoespaçada (Fira Code) e paleta em tons de **roxo**.

🔗 **Link do site:** [natyylimaf.github.io/portfolio](https://natyylimaf.github.io/portfolio)

## 💻 Como rodar localmente

```bash
git clone https://github.com/natyylimaf/portfolio.git
cd portfolio
```

Depois, abra o `index.html` no navegador. Não é preciso instalar nada.

## 🧠 Conceitos praticados

- HTML semântico e acessibilidade
- Variáveis CSS, Flexbox e design responsivo
- Pseudo-elementos (`::before` e `::after`) e animações com `@keyframes`
- Manipulação do DOM e eventos (`scroll`, `click`)
- `setInterval` e `matchMedia`
- Versionamento com Git e GitHub
